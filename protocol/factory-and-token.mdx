## Factory

`JuggervaultAssetTokenFactory` is the registry. It does not hold units.

`createAssetToken` consumes the issuer nonce and checks a factory-admin signature over the name, symbol, supply arguments, issuer, and asset record. If an origination fee is set, that fee is pulled from the caller in an approved settlement currency. The new token records the offer operator as issuer. The sale contract is marked exempt so it can move units during settlement.

| Function | Who may call | Effect |
| --- | --- | --- |
| `createAssetToken` | A caller holding a valid factory-admin signature | Deploys one asset token and registers the issuer. |
| `setTokenDeployer` | Factory admin | Points new offerings at a token implementation. Existing tokens are unchanged. |
| `setSale` | Factory admin | Registers the sale contract that mints on purchase. |
| `setDividendDistributor` | Factory admin | Registers the distributor used by every offering. |
| `setPaymentTokenApproval` | Factory admin | Allows or removes a settlement currency. |
| `setPlatformFeeWallet` | Factory admin | Sets the account that receives the primary execution fee. |
| `setOriginationFeeConfig` | Factory admin | Sets the currency and destination of the creation fee. |

## Asset token

`JuggervaultAssetToken` is one contract per offering. The issuer receives administration of that token and is registered at creation. If the creation supply is not zero, that amount is minted to the issuer at launch. Primary units sold later are minted only by the sale contract.

A transfer checks pause, freeze, registration, and exemption. A mint to an account that is not registered fails unless that account is exempt. The buyer must still be registered, because the sale checks registration before it mints. Every movement notifies the dividend distributor.

Registration on the token is the contract function `batchWhitelist`. In the product this is completed registration, not a separate list the partner manages.

| Function | Who may call | Effect |
| --- | --- | --- |
| `mintForPrimarySale` | Sale contract only | Mints units to the buyer. Refuses the mint if it would pass the maximum supply. |
| `batchMint` | Issuer, or the platform relayer with the issuer signature | Mints to named accounts, still subject to the maximum supply. |
| `batchWhitelist` | Issuer, or the platform relayer with the issuer signature | Registers or removes accounts that may hold the offering. |
| `batchSetExemption` | Compliance authorization | Lets an account move units without the usual registration check on its side. |
| `batchFreeze` | Issuer or compliance | Stops an account from sending or receiving while frozen. |
| `setPaused` | Issuer or compliance | Pauses or resumes every transfer. |
| `depositDividends` | Dividend distributor only | Reserves settlement currency on the token for claims. |
| `releaseDividend` | Dividend distributor only | Pays a claim from that reserve. |
| `recoverTokens` | Issuer, or the platform relayer with the issuer signature | Recovers stray tokens or the network token. Amounts reserved for dividends cannot be taken. |
| `permit` | Holder signature | Approves a spender. Used by purchases, buybacks, and dividend funding. |

A platform relayer may submit an action the issuer or the compliance officer has signed. A direct call must come from that signer, and the signature field must be empty.
