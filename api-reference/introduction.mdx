These pages are the complete Partner API. They are generated from the OpenAPI description. Each page shows the method, path, required scope, parameters, and request body.

The Partner API does not include routes for accounts, keys, cash movement, sessions, or administration. Account opening and custody are described in [Accounts and custody](/guides/accounts-and-custody).

## Conventions

- The server URL already includes `/api/partner/v1`. Paths on these pages are relative to that prefix.
- Send JSON with `Content-Type: application/json` on `POST` requests.
- Authenticate with `Authorization: Bearer` or `X-Api-Key`. See [Authentication](/guides/authentication).
- Success bodies use one of these fields: `pathways`, `catalog`, `listing`, `investor`, `kyc`, `registration`, `intent`, or `holdings`. A purchase-intent read also includes `externalUserId`.
- Amounts may be JSON numbers or decimal strings. Parse both.
- Times are ISO 8601 in UTC.

## Scopes on each route

The endpoint page states the required scope. A request without that scope returns `403` before the handler runs.
